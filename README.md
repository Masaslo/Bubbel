# Bubbel 🫧
Welcome to bubbel

An Android native project designed for people with misophonia or other auditory conditions that affect their lives. It is intended primarily for use in classrooms with wireless microphones.

## Overview
This app uses noise isolation to drown out any other sounds other than the voice that is selected.

*Features*:
* Voice isolation
* White noise generation
